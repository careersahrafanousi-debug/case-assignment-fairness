Case Assignment Fairness and SLA Control Tower

ClearPath Case Services (fictional) · 15,908 cases · 2 January to 30 June 2026. Leadership asked which team was underperforming. Workload per analyst hour is near-equal across all five teams, yet SLA compliance ranges from 26% to 84%. The cause is a target and a routing method, not a team.

Fully synthetic data · no employer, patient or confidential information

How this page is built. Every value comes from a SQL query stored in dashboard/dashboard_config.json and run against data/cases.db by src/build_dashboard.py. Nothing is typed in by hand, so the dashboard cannot drift away from the analysis in sql/. Rebuild with python src/load_sqlite.py && python src/build_dashboard.py.

Limitations. Reassignment is treated as a routing failure, which overstates it because no reason code separates misroutes from legitimate escalations. SLA is measured in elapsed clock hours, not business hours, because the source has no business calendar. The complexity score weights are analyst judgement and were not fitted to outcomes. The data is fully synthetic, so the relationships shown here were built into the generator — what transfers is the method, not the conclusion.

Source: synthetic data generated by src/generate_data.py, seed 8821. No employer data, patient information, protected health information or confidential business information is used. Analyst performance is reported by tenure band only, never by individual.
